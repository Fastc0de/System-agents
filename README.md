# System-agents

Sistema de orquestación de agentes para vibe coding con Claude Code. Tú conversas solo con un **orquestador**. Él convierte tu visión en **diagramas de flujo detallados** y delega la construcción a **subagentes especializados** que siempre arrancan con la **memoria del proyecto** en contexto.

> **Estado: concepto v0.** Todavía no hay nada implementado. Primero acordamos la visión.

## Empieza aquí

- **[Visión del sistema](docs/concepto/VISION-DEL-SISTEMA.md):** qué hará, cómo trabajará, cómo se disciplinan las cargas de trabajo y qué decisiones quedan abiertas.
- **Diagramas** (`.excalidraw` editables, con vista previa `.png`):
  - [Arquitectura](docs/concepto/diagramas/01-arquitectura.png)
  - [Ciclo de vida: fases y gates](docs/concepto/diagramas/02-ciclo-de-vida.png)
  - [Memoria integrada y contexto](docs/concepto/diagramas/03-memoria-y-contexto.png)
  - [Anatomía de un flujo](docs/concepto/diagramas/04-anatomia-de-un-flujo.png)

Para editar un diagrama, abre el `.excalidraw` en [excalidraw.com](https://excalidraw.com) (menú *Open*) o con la extensión de Excalidraw de VS Code.
